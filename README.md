## 1. 글 쓰기 한눈에 보기

글 하나는 **폴더 하나**예요. 폴더 이름이 글 주소가 되고, 글 정보와 본문과 사진을 모두 그 안에 둬요.

```text
src/content/posts/daily/first-snow/     ← 주소: /posts/first-snow/
├── info.md      ← 글 정보 (제목, 태그 …)
├── index.md     ← 본문
└── image.jpg    ← 사진
```

1. **폴더 만들기**: `src/content/posts/daily/`(일상) 또는 `study/`(공부) 안에 새 폴더를 만들어요.
   이름은 영어 소문자·숫자·하이픈(-)으로 지어요. 예: `first-snow`
2. **`info.md`**: 제목을 적어요. 나머지는 비워 둬도 돼요.

   ```md
   title: 첫눈 온 날
   tags: [겨울, 사진]
   ```

3. **`index.md`**: 글을 써요. 사진은 **Ctrl + V**로 붙여 넣어요.
4. **미리보기**: **Ctrl + Shift + V**
5. **올리기**: 소스 제어(**Ctrl + Shift + G**)에서 메시지를 적고 **Ctrl + Enter**. 몇 분 뒤 사이트에 올라가요.

폴더와 두 파일은 명령어로 한 번에 만들 수도 있어요.

```bash
npm run new -- daily first-snow "첫눈 온 날"     # 공부 글은 study
```

## 2. 글 정보: info.md

한 줄에 `항목: 값` 하나씩 적어요. **`title`만 꼭 적으면 되고**, 비워 둔 항목은 저절로 채워져요.

| 항목 | 비워 두면 | 직접 적을 때 |
| --- | --- | --- |
| `title` | (필수) | `title: 첫눈 온 날` |
| `description` | 본문 첫 문단(100자 안팎) | 목록·검색 미리보기에 보일 한 줄 요약 |
| `date` | 처음 커밋한 시각 | `2026-11-28` 또는 `2026-11-28 21:30` |
| `category` | 글 폴더(`daily/`, `study/`) | `daily` 또는 `study` |
| `tags` | 태그 없음 | `[겨울, 사진]` (`#`은 붙이지 않아요) |
| `cover`, `coverAlt` | 대표 이미지 없음 | `cover: ./cover.jpg`, `coverAlt: 눈 쌓인 골목` |
| `draft` | 바로 공개 | `draft: true`면 사이트에 올라가지 않아요 |

- 값에 콜론(`:`)이나 `#`이 들어가면 큰따옴표로 감싸요. 예: `title: "오늘의 기록: 맑음"`
- `info.md` 대신 본문 맨 위 `---` 두 줄 사이에 적어도 돼요. 둘 다 적으면 본문 쪽이 우선이에요.

## 3. 본문 쓰기: Markdown 빠른 참조

| 쓰고 싶은 것 | 이렇게 적어요 |
| --- | --- |
| 문단 | 문단 사이에 **빈 줄**. 줄을 한 번만 바꾸면 화면에서는 이어진 한 문단이 돼요 |
| 소제목 | `## 소제목`, 그 아래는 `### 작은 소제목` (`#` 하나는 글 제목 자리라 쓰지 않아요) |
| 굵게 | `**굵게**` |
| 링크 | `[보일 글자](https://example.com)`, 내 글은 `[지난 글](/posts/first-snow/)` (끝에 `/`) |
| 목록 | `- 항목` 또는 `1. 항목` |
| 인용 | `> 인용문` |
| 사진 | `![사진 설명](image.jpg)` |
| 사진 + 캡션 | `![사진 설명](image.jpg "사진 아래 작은 글씨")` |
| 코드 | 줄 앞뒤에 ```` ```js ```` 와 ```` ``` ```` |
| 각주 | 문장 끝에 `[^1]`, 글 맨 아래에 `[^1]: 각주 내용` |
| 구분선 | `---` (앞뒤에 빈 줄) |

표, 할 일 목록(`- [ ]`), 취소선(`~~글자~~`)도 돼요.
사진 여러 장을 나란히 놓거나 동영상을 넣으려면 `index.md`를 `index.mdx`로 바꿔요([GUIDE.md 5·6장](GUIDE.md#5-사진-넣기)).

## 4. 사진 넣기

- **붙여 넣기**: 카톡 등에서 사진을 복사해 `index.md`에 **Ctrl + V**. 사진이 글 폴더에 저장되고 사진 줄이 들어가요.
- **스크린샷**: **Win + Shift + S**로 영역을 고른 뒤 `index.md`에 **Ctrl + V**. 붙여 넣기와 같아요.
- **파일 끌어다 놓기**: 사진 파일을 **Shift를 누른 채** 본문으로 끌어다 놓아요.
- 들어간 줄의 `[ ]` 안은 **사진 설명**으로 바꿔 적어요.
- **커밋할 때 사진이 자동으로 줄어요.** GitHub 저장소가 무거워지지 않게 하려는 거예요.
  - **사진**: 붙여 넣으면 PNG로 저장되는데, 커밋할 때 JPG로 바뀌고 글 속 경로도 함께 고쳐져요. (카톡 사진 16.8MB → 0.2MB)
  - **스크린샷**: 글자가 뭉개지지 않게 **PNG 그대로** 줄여요. 작은 캡처와 투명 배경 그림은 손대지 않아요.
  - **JPG**: 1MB가 넘으면 같은 이름으로 줄여요.
  - 긴 변은 1600px 이하로 줄고, 사진 속 **촬영 위치(GPS) 같은 정보는 지워져요.**
- 사진은 저장소에 함께 올라가야 사이트에 보여요(`.gitignore`로 빼면 안 돼요). 한 번 올린 사진은 지워도 Git 기록에 남으니, 줄여서 올리는 게 중요해요.
- 사이트는 사진을 화면 크기에 맞는 가벼운 형식으로 다시 만들어 보여 줘요. 원본이 커도 방문자에게는 가볍게 보여요.
- 아이폰 **원본 파일**(`.heic`)은 쓸 수 없어요. 들어 있으면 커밋이 멈추고 알려 주니 JPG로 바꿔서 넣어요(카톡으로 받은 사진은 괜찮아요).
- **용량 확인**: `npm run size`로 사진·저장소·사이트 용량과, 앞으로 올릴 수 있는 사진 수를 볼 수 있어요.
  사진이 장당 0.2MB 안팎으로 줄어서 GitHub 권장 한도(1GB)까지 수천 장이 들어가요.

## 5. 미리보기와 올리기

**미리보기**
- VS Code에서 **Ctrl + Shift + V**(옆에 띄우려면 **Ctrl + K** 다음 **V**). 글과 사진을 확인하기엔 이걸로 충분해요.
- 사이트 모양 그대로 보고 싶을 때만 터미널에서 `npm run dev`를 켜고 <http://localhost:4321>을 열어요.

**올리기**
1. 소스 제어(**Ctrl + Shift + G**)에서 메시지(예: `새 글: 첫눈 온 날`)를 적고 **Ctrl + Enter**.
2. 이 프로젝트는 커밋하면 바로 push되도록 설정되어 있어요(`.vscode/settings.json`). 변경한 파일을 따로 고르지 않아도 모두 함께 올라가요.
3. GitHub가 사이트를 다시 만들어 **몇 분 뒤** 반영돼요. 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있어요.
4. 바뀐 게 안 보이면 브라우저에서 **Ctrl + Shift + R**로 새로고침해요(최대 10분 캐시).

**쓰다 만 글**은 `info.md`에 `draft: true`를 두면 커밋해도 사이트에 올라가지 않아요. 다 쓰면 그 줄을 지우고 다시 커밋해요.

## 6. 글 작성 요령

- **첫 문단에 핵심을** 써요. 요약을 따로 적지 않으면 첫 문단이 목록과 검색 미리보기에 그대로 쓰여요.
- **제목은 짧고 구체적으로.** 목록에서 한 줄에 읽히는 길이가 좋아요.
- **소제목은 `##`부터.** `##`이 두 개 이상이면 넓은 화면에서 글 왼쪽에 목차가 생겨요.
- **문단은 짧게**, 빈 줄로 나눠요. 글 → 사진 → 글처럼 사진을 문단 사이에 두면 읽기 편해요.
- **사진 설명은 꼭** 적어요. 사진이 안 뜰 때와 화면 낭독기 사용자에게 보여요.
- **스크린샷은 필요한 부분만** 캡처해요(Win + Shift + S로 영역 선택). 용량이 작고, 글 안에서 글자도 더 크게 보여요.
- **코드는 스크린샷 대신 코드 블록**으로 적어요. 검색·복사가 되고 용량은 거의 들지 않아요. 표는 Markdown 표로 써요.
- **태그는 2~3개**, 같은 말은 늘 같은 표기로(`사진`과 `Photo`를 섞지 않기). 태그 페이지가 갈라지지 않아요.
- **공부 글**: 코드 블록에는 언어 이름(```` ```c ````, ```` ```python ````)을 적고, 출처는 링크나 각주로 남겨요.
- **폴더 이름(주소)은 올린 뒤 바꾸지 않아요.** 바꾸면 예전에 공유한 링크가 끊겨요. 제목과 본문은 언제든 고쳐도 돼요.
- 올린 글을 고치고 싶으면 파일을 고치고 다시 커밋하면 돼요. 작성일은 처음 올린 날 그대로예요.

## 7. 문제가 생겼을 때

| 증상 | 확인할 것 |
| --- | --- |
| 커밋했는데 사이트에 안 보여요 | 몇 분 기다린 뒤 **Ctrl + Shift + R**. `info.md`에 `draft: true`가 남아 있는지 |
| Actions 탭에 빨간 X가 떴어요 | 실행을 눌러 빨간 단계의 메시지를 봐요. 대개 `info.md` 형식이나 사진 경로 문제예요 |
| `글 정보를 읽을 수 없습니다` | `info.md`에서 값에 `:`나 `#`이 있으면 큰따옴표로 감싸요 |
| `title: Required` | `info.md`에 `title` 줄이 없어요 |
| 사진이 안 보여요 | 사진 파일이 글 폴더에 있는지, 이름의 대소문자가 본문과 같은지 |
| 커밋이 "아이폰 원본 사진(HEIC)" 메시지와 함께 멈췄어요 | 그 사진을 JPG로 바꿔서 넣어요. 카톡으로 보낸 사진을 복사해 붙여 넣으면 돼요 |
| 내 블로그 링크가 404예요 | 주소 끝에 `/`를 붙였는지(`/posts/first-snow/`) |

더 많은 오류와 해결 방법은 [GUIDE.md의 "문제가 생겼을 때"](GUIDE.md#12-문제가-생겼을-때)에 있어요.

## 8. 사이트 고치기

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 소개 페이지·홈 상단 (이름, 한 줄 소개, 링크, 학력 등) | `src/data/profile.ts`. 배열을 비우면(`awards: []`) 그 칸이 숨겨져요 |
| 프로필 사진 | `src/assets/profile.jpg`에 넣고 `profile.ts`의 `// import photo …`, `// photo,` 두 줄에서 `//`를 지워요 |

| 상단 메뉴 이름 | `src/consts.ts`의 `NAV` (`label`만 바꿔요) |

| 글꼴, 글자 크기 | `src/styles/tokens/typography.css` |
| 여백, 본문 폭, 넓은 화면 틀 | `src/styles/tokens/layout.css` |

글을 지우려면 글 폴더를 통째로 지우고 커밋해요.

## 9. 개발 메모

**준비물**: [Node.js](https://nodejs.org) 22.23.4 이상, Git, VS Code. 처음 한 번 `npm install`을 실행해요
(커밋할 때 사진을 줄이는 Git hook도 이때 연결돼요).

| 명령어 | 하는 일 |
| --- | --- |
| `npm run new -- <daily\|study> <주소> "제목"` | 글 폴더와 `info.md`(초안), 본문(일상 `index.md`, 공부 `index.mdx`)을 만들어요 |
| `npm run dev` | 미리보기 서버 <http://localhost:4321>. 초안도 보여요 |
| `npm run images` | 글 폴더의 큰 사진을 줄여요(사진은 JPG로, 스크린샷은 PNG 그대로, 촬영 정보 지우기). 커밋할 때 자동으로 실행돼요 |
| `npm run size` | 사진·Git 저장소·사이트 용량과 남은 여유를 보여 줘요 |
| `npm run build` | 배포용 사이트를 `dist/`에 만들어요. 오류를 미리 확인할 때 써요 |
| `npm run check` | 코드 타입 검사 |

**배포**: `main`에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 `npm ci` → `npm run build`를 거쳐 GitHub Pages에 올려요.
저장소 Settings → Pages → Source가 **GitHub Actions**여야 해요.

**자동으로 해 주는 것**

| 무엇 | 어디서 |
| --- | --- |
| `info.md` 읽기, 비워 둔 글 정보 채우기 | `src/content.config.ts`, `src/lib/excerpt.ts` |
| 붙여 넣은 사진을 글 폴더에 저장, 커밋하면 push | `.vscode/settings.json` |
| 커밋 직전 사진 줄이기 (PNG → JPG, 큰 JPG, 촬영 정보) | `.githooks/pre-commit` → `scripts/convert-images.mjs` |

> Windows에서 `npm.ps1 파일을 로드할 수 없습니다`라는 오류가 나면 PowerShell에서
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`를 한 번 실행하거나, `npm` 대신 `npm.cmd`를 써요.
