영문을 기준으로 정해진 CSS 기본값은 한글에 그대로 맞지 않을 때가 많습니다. 한글은 글자 하나하나가 네모난 틀을 꽉 채우기 때문에, 같은 크기라도 영문보다 빽빽해 보입니다. 아래 세 가지만 손봐도 본문이 훨씬 편하게 읽힙니다.

## 줄 간격

브라우저의 기본 줄 간격(`normal`)은 글꼴에 따라 다르지만 대략 1.2 안팎입니다. 한글 본문에는 너무 좁습니다.

<Figure src={lineHeight} alt="같은 문단을 줄 간격 1.5, 1.8, 2.1로 나란히 놓은 비교 그림. 가운데 문단이 강조되어 있다.">
  왼쪽부터 줄 간격 1.5, 1.8, 2.1. 한글 본문에는 가운데 정도가 무난하다. 더 자세한 기준은 [W3C 한국어 텍스트 레이아웃 요구사항](https://www.w3.org/TR/klreq/)을 참고.
</Figure>

용도에 따라 알맞은 줄 간격도 다릅니다.

| line-height | 느낌 | 어울리는 곳 |
| --- | --- | --- |
| 1.4 | 빽빽함 | 표, 캡션처럼 짧은 글 |
| 1.6 | 조금 촘촘함 | 목록, 버튼 같은 UI 글자 |
| 1.8 | 편안함 | 긴 본문[^1] |
| 2.0 | 느슨함 | 시, 짧은 에세이 |

## 단어 단위 줄바꿈

CSS 기본값에서 한글은 글자 단위로 줄이 바뀝니다. 그래서 "가독성"이라는 단어가 "가독"과 "성"으로 나뉘어 두 줄에 걸치기도 합니다. `word-break: keep-all`을 지정하면 띄어쓰기 단위로만 줄을 바꿉니다.

```css
body {
  line-height: 1.8;
  word-break: keep-all; /* 한글을 어절 단위로 줄바꿈 */
  overflow-wrap: break-word; /* 그래도 긴 URL은 넘치지 않게 */
}
```

<Callout type="warning">
`keep-all`만 지정하면 아주 긴 URL이나 띄어쓰기 없는 문자열이 화면 밖으로 넘칠 수 있습니다. `overflow-wrap: break-word`를 꼭 함께 지정하세요.
</Callout>

## 한 줄의 길이

한 줄이 너무 길면 다음 줄의 시작을 찾느라 눈이 쉽게 지칩니다. 한글 본문은 한 줄에 35~45자 정도가 적당하다고들 합니다.[^2] 이 블로그는 본문 폭을 700px로 두었고, 17px 글자 기준으로 한 줄에 40자 남짓이 들어갑니다.

</Quote>

## 정리

세 가지를 한곳에 모으면 다음과 같습니다. 값을 변수로 빼 두면 나중에 한 곳만 고쳐도 됩니다.

```css
:root {
  --text-base: 1.0625rem; /* 17px */
  --leading-body: 1.8;
  --width-prose: 700px;
}

.prose {
  max-width: var(--width-prose);
  font-size: var(--text-base);
  line-height: var(--leading-body);
  word-break: keep-all;
  overflow-wrap: break-word;
}
```

모두 한 줄짜리 설정이지만, 함께 적용하면 차이가 분명하게 느껴집니다.

[^1]: 글자가 클수록 줄 간격 비율은 조금 줄여도 됩니다. 제목에는 보통 1.2~1.3 정도를 씁니다.
[^2]: 정해진 표준이 있는 것은 아니고, 글꼴과 글자 크기에 따라 달라집니다.
